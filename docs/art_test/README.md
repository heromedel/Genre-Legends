# Art test (2026-11-09)

(Note) A test of heromedel's five-pass vector style (outline, fill, shading, highlights, details, per component),
for a possible art overhaul. Nothing here is in the game yet.

- `*.svg`: the new versions, in game units at the game's sizes, light from the top-left. Flat shapes only, so they
  can be ported to the game's own painter.
- `*_compare.png`: current art next to the new art, labelled A and B for the cold reviewers. New is A for the ship
  and the Hive Carrier, and B for the mech and the Dart.
- The current art was captured with the debug gallery: `index.html?gallery=ship&zoom=4` (also `mech`, `dart`, or any boss id).
